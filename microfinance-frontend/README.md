# Microfinance & Rural Lending Management System — Frontend

Modern Vite + React.js 18 + Redux Toolkit enterprise PWA web application for microfinance and rural lending operations.

## Stack & Features
- **React 18** with Vite build tool
- **Redux Toolkit** for centralized state management across 16 domain slices
- **React Router 6** with role-based route guards
- **i18next** multilingual support (English, Hindi, Tamil, Telugu, Kannada)
- **Recharts** charts for PAR trend analysis, AUM growth, and collection efficiency
- **PWA Offline Support** via Service Worker and IndexedDB queueing
- **Lucide Icons & Glassmorphism Design System**

## How to Run
```bash
npm install
npm run dev
```
Dev Server running on `http://localhost:5173` (proxies `/api` requests to Spring Boot on `http://localhost:8080`).
